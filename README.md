# Shadowline

A comprehensive Batman universe management system - the ultimate Batcomputer for tracking characters, locations, stories, and intel across the Shadows of Gotham narrative.

## Features

- **Bible System**: Comprehensive database for characters, locations, gadgets, and intel
- **Editor**: Advanced writing environment for stories and scenes
- **Volumes & Outlines**: Structured story organization system
- **Gallery**: Media management for images, audio, and documents
- **Search**: Advanced filtering and discovery across all content
- **Maps**: Interactive navigation through Gotham locations
- **Authentication**: Secure access with invitation-based guest system

## Getting Started

1. Install dependencies: `npm install`
2. Run the development server: `npm run dev`
3. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

- `/src/app` - Next.js 15 app directory with pages and layouts
- `/src/components` - Reusable UI components
- `/src/hooks` - Custom React hooks for state management
- `/src/lib` - Utility functions and configurations

Built with Next.js 15, TypeScript, Tailwind CSS, and Vercel deployment.
