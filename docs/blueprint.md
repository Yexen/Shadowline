# **App Name**: Shadows of Gotham Writer

## Core Features:

- Draft Management: Create, rename, and delete drafts.
- Canon Integration: Insert relevant lore from the user's 'bible' (stored in the same browser) into the draft.
- Export: Export drafts as .txt or .md files.
- Save/Autosave: Manually save drafts or rely on autosave functionality.
- Word Count: Display the current word count of the draft.
- Preview: Toggle a preview pane to see the draft rendered (basic Markdown).
- Keyboard Shortcuts: Provide keyboard shortcuts for common actions (save, insert canon, export).
- Bat-Signal Easter Egg: A button to trigger a visual 'Bat-Signal' effect on the page.
- Sliding Sidebar: Implement a sliding sidebar for improved navigation and workspace accessibility.
- Home Page: Display suggested YouTube videos and news about the Batman universe on the home page.
- AI Code Generation: Integrate with AI models like Claude and ChatGPT to generate code from user descriptions and write that code to CSS or Javascript sections.
- AI Writing Assistant: Integrate personal ChatGPT account for AI-assisted writing and content generation.
- Grammarly Integration: Integrate Grammarly for real-time grammar and style checking in the writing space.
- Bible Button with Notion-like Organization: Implement a 'Bible' button with Notion-inspired organization tools for managing lore and world-building details.
- Login Page: Create a Batman-themed login page to restrict access to the writing space via password protection.
- About Writer Section: Implement an 'About Writer' section to provide context or information about the author or the project.
